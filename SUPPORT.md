# Getting help

## Using Red Tape Navigator

- Start with the **Help** page inside the app (`/help`). It answers the most common questions in English, Hindi and Bengali.
- Read the [README](README.md) for what the product does and how to run it.
- The app gives **guidance, not legal advice**. For a final answer, confirm with the issuing authority (for example the municipal corporation, FSSAI or the relevant ministry).

## Reporting something

Use the issue forms: <https://github.com/RajdipDhar2007/Red_Tape_Navigator/issues/new/choose>

| You want to report | Use |
|---|---|
| Something is broken | **Bug report** |
| A fee, timeline, authority or document list looks wrong | **Rule or data correction** (please link the official source) |
| An accessibility barrier | **Accessibility barrier** (see also [ACCESSIBILITY.md](ACCESSIBILITY.md)) |
| An idea | **Feature request** |
| A security problem | Do **not** open an issue. Follow [SECURITY.md](SECURITY.md). |

## Please never share

Real Aadhaar or PAN numbers, bank details, passwords, one-time codes, API keys or personal documents, in issues, comments or screenshots. Use fake values.

## Response times

This is a student-built project. We read every report and answer as soon as we can, but we cannot promise a fixed response time.
