# Assumptions

- Local machine has Python 3.14 only; the project targets Python 3.12 (Docker/CI use 3.12). Code avoids 3.13+ features.
- Tests run on SQLite (aiosqlite) and in-memory fakes for Redis so they work without services; production uses
  PostgreSQL + pgvector + Redis. Vector search falls back to keyword/cosine-in-Python when pgvector is absent.
- Job runner: **Arq** (Redis-based, async-native).
- Real government form PDFs and live portal scraping can't be validated offline. Form templates ship with
  clearly marked **placeholder PDFs** generated by `scripts/make_placeholder_forms.py`; `docs/INTEGRATIONS.md`
  explains how to add real ones.
- The curated **seed rules pack** (`backend/app/kb/seed/`) encodes publicly known requirements for the demo
  scenario with source URLs; its confidence is capped (<1.0) and marked "seed – verify live". Regulatory
  details (fees, timelines) in seeds are illustrative and must be verified before pilot.
- Without `ANTHROPIC_API_KEY` the system uses a deterministic fallback for intake/research, labelled in UI.
- Repository is private on GitHub by default; push after each milestone as the owner requested.
- No real DigiLocker / Aadhaar e-Sign / WhatsApp credentials exist; all integrations default to labelled mocks.
